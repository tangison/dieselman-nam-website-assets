# Dieselman Nam Website Asset Pack

Production handoff for a future client demo website. This pack contains authentic supplied source material, restored web-ready imagery, transparent vector logos, responsive delivery formats, visual rules, verified business facts, content direction, and a build prompt.

## Start here

1. Read `docs/PRODUCT.md`.
2. Read `docs/BRAND.md`.
3. Read `docs/BUILD_PLAN.md`.
4. Read `docs/CONTENT_PLAN.md`.
5. Use `prompts/MASTER_BUILD_PROMPT.md` as the implementation brief.
6. Preserve the `assets/source/` files. They are evidence and must not be overwritten.

## Asset rules

- Use the supplied or restored client imagery before generating anything.
- Do not use stock photography or Unsplash.
- Use documentary client imagery as evidence. Use the clearly disclosed generated support set only for atmosphere and service explanation.
- Do not present generated scenes as documentary proof.
- The SVG logos are transparent and must remain vector assets.
- Use AVIF first, WebP as the fallback, and PNG only where lossless source quality is required.
- The navigation medallion should be created with CSS around the transparent logo. Do not bake a circular background into the logo.
- Exact contact information must be preserved.

## Image coverage

- 6 restored documentary client scenes

- 10 original supporting truck, trailer, alignment, diagnostics, workshop, and texture visuals
- Responsive WebP and AVIF delivery files for every master
